      ¿Conoces un lugar que depende de la marea?

      Un paso a una isla, un camino por la playa, una zona para mariscar o una rampa para botes. Cuéntanos y lo calibramos para la app.

      Cómo se calcula la marea

      Para los próximos 10 días se usa el pronóstico del modelo oceánico de Open-Meteo, descargado al abrir la app.

      Para cualquier otra fecha, la marea se calcula con sus componentes astronómicas (la Luna y el Sol), igual que las tablas oficiales. Las constantes se obtienen de más de un año de datos de cada punto y se recalculan periódicamente. Comparado con el pronóstico, acierta la hora de pleamares y bajamares con unos ±3 minutos y la altura con unos ±5 cm. Funciona sin internet.

      El viento y la presión pueden mover la marea real unos centímetros o minutos. No es la tabla oficial del SHOA: cruza con margen y mirando el agua.
